How to connect Claude (MCP)

Claude reads the board through a read-only MCP server at {{ mcp_base }}/mcp - three tools: get_scorecard, get_check_in_status (who still owes a number, split into not-yet-late and late, each with the DRI's Slack member ID so Claude can tag them) and list_metrics. No writes: numbers stay something a person reports, so the audit trail keeps naming the person.

To connect it, create a read only token below - the page then shows a ready-to-paste connector URL of the form {{ mcp_base }}/mcp/t/<token>. Tokens are stored hashed, so that URL can only be shown the once; rotate the token to get a fresh one. In Claude: Settings › Customize › Connectors › Add › Add custom connector, paste the URL, leave the OAuth fields empty. Opening the URL in a browser returns 405 - it is a POST-only JSON-RPC endpoint, not a page, and that response means it is working. The token's Last used below is how you confirm Claude connected.

The URL carries the token, so it lands in the reverse proxy's access log. Keep it read-scoped, and rotate if the URL leaks.
