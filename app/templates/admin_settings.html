TV views

Which boards the TV cycles through, and how long each one stays up.

How rotation decides

The TV decides server-side on its own poll, so a unit with no keyboard rotates by itself and two screens in the same room stay in step. A view with nothing to show is skipped — “Act on this” is empty exactly when nothing is red, and a blank screen reads as broken. Pick one view and set the seconds to 0 to hold it still.

What the screensaver does

CEO view

What the CEO view shows

The seven metrics every CEO should track — revenue, expenses, leads, conversions, CAC, retention, profit — on one TV screen: the growth funnel with its close rate, the cost to win and keep a customer, and revenue against expenses and profit as one picture. Each slot is filled by one of your metrics. Leave a slot on auto-detect and it takes the first live metric with a matching name; pick one to be explicit. Tick “CEO metrics” under TV views above to put it in the rotation, or add all seven at once from Admin › Metrics › Start from a template.

CEO view · categories

How categories work

Break a tile down into the parts that add up to it — expenses by category, revenue by service line, leads by source. On the CEO metrics page, clicking the tile opens each part with its share, its target and its last few weeks, and says when the parts no longer add up to the total. The TV view stays as it is. Each category is an ordinary metric created in the same section as the tile’s metric, with the same unit and owner, so it can be given a target and written by an automation through POST /api/v1/ceo/<tile>/breakdown. Removing a category here only unlinks it; its history stays.

Check-in nudges

{{ 'ENABLED' if nudges_enabled else 'DISABLED' }}

Anyone who has not entered last week's numbers gets a Slack DM listing exactly what is missing, with a one-tap link to their My Numbers page — and they can simply reply 1: 12, 2: G to record values straight from Slack (no AI involved; replies are parsed literally). Nudges go out Monday 4:00 PM and/or Tuesday 9:00 AM Chicago, each metric nudged at most once per round. Requires the Slack alerts master switch ON, plus below: the public URL for links, and for typed replies the signing secret above and this one-time Slack app setup — at api.slack.com/apps: bot scopes chat:write + im:history (add chat:write.customize and every message we send carries the Scorecard icon instead of Slack's default; without it messages still go out, plain); Event Subscriptions ON with Request URL {{ public_base_url or base_url }}/slack/events; subscribe to bot event message.im; reinstall the app. While you are in there, give the app its icon under Basic Information → Display Information: upload this 512×512 PNG — Slack has no API for the app icon, so it is the one setup step nothing here can do for you. Each user's Slack member ID is set on the Users page.
